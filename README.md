# ADME AI Operating System

A living map of ADME's AI workflows, skills, gaps, handoffs, and planned capabilities.

## MVP

The first mapped workflow is the White Paper Cycle. The site also groups current skills into broader company capability areas so the architecture can grow over time.

Skill status colours:

- Blue: active core skill
- Green: supporting skill
- Grey: unavailable or planned skill
- Yellow: active skill that needs refactoring

## Current direction

The AI Workflow Architect maintains the logic of the architecture. This repository is the controlled source for the human-readable map. The MVP is static and can be deployed directly to Vercel.
